## ГРАБЛИ (дополнение)

- remote schools-map-mathex — чистый https://github.com/volgarevmaxim-bit/schools-map-mathex.git
  (GCM работает); transport — school-transport-availability.git.
- Линтер патчей на portal/app.js даёт ложную ошибку (node путь «C:\c\...») — проверять
  node --check portal/app.js.
- apply пропускает школу ЦЕЛИКОМ, если хоть одна её новая точка без координат: перед apply
  в merge_plan должно быть 0 точек с lat=null.

  нумерации -bK часть теряется (было 10 из 344) — после prepare сверять null и догеокодировать
  (geocode_yandex.py догоняет только null-точки).
- Правки merge_plan делать ПОСЛЕ prepare (prepare их затёр бы); owner-правки ролей —
  отдельным скриптом перед apply.
- search_files/patch НЕ принимают MSYS-пути /c/... — использовать Windows-пути C:\... или
  terminal+python.
- Raw githubusercontent может отдавать прокси-кэш — сверять через API contents (Accept:
  application/vnd.github.raw); Pages CDN ~1 мин.
- Старые грабли действуют: лимиты 2ГИС (суточные 50 + per-minute pt ~25/мин), ключ в
  winreg, .venv/Scripts/python.exe (transport), DATE=2026-10-14.
