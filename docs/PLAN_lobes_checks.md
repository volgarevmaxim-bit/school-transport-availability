## Что делаем

Для каждого лепестка: endpoint = школа + луч (азимут конвенции stage6 из lobes_*.csv,
дальность r_max_km). Один запрос на лепесток:

- ОТ: pt-маршрут школа→endpoint, старт 05:30Z, DATE=2026-10-14 (та же семантика, что у
  зон: «от школы»), enable_schedule. Проверка: total_duration ≤ min (зона утверждает
  достижимость) + коридор из movements (metro.line_name и пр.) против гипотезы.
- Авто: routing школа→endpoint, utc = 08:30 МСК − min (гипотеза A: utc = отправление),
  traffic_mode=statistics. Проверка: duration/коридор; учёт известного caveat
  (изохрона оптимистична на дальних сегментах до ~2×).

Вердикт по ratio = duration/(min×60): подтверждено ≤1.2; частично ≤1.5; противоречит >1.5
(для авто — с пометкой caveat). Ошибки 4xx — терминальные; сетевые ERR — ретрай.
